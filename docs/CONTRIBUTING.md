# Contribuir

1. Abre una rama `feature/<tema>`.
2. Mantén funciones matemáticas puras en `src/core` o `models.ts`.
3. Agrega una prueba por resultado numérico relevante y explica límites de cada ejemplo.
4. Ejecuta `npm run typecheck`, `npm test` y `npm run build` antes del PR.
5. En el PR indica: objetivo didáctico, capítulo del libro asociado, fórmulas implementadas y validaciones.

Los cambios en simulaciones no deben convertir indicadores didácticos en herramientas de decisión sin validación independiente.
